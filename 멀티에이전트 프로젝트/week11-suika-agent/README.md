# Week 11 콩쌤 수박게임 에이전트

이 폴더는 Week 11 과제용으로 만든 이동 가능한 규칙 기반 에이전트 v0입니다.

기존 `일정공지 에이전트` 예시는 수업 일정과 알림 문구를 정리하는 구조였고, 여기서는 같은 구조를 `콩쌤 수박게임 작업공지 에이전트`로 바꾸었습니다. 에이전트는 기존 게임 코드를 직접 수정하지 않고, `context.md`와 `todo.md`를 읽어 현재 프로젝트 맥락, 작업 계획, 12주차 확장 방향을 정리합니다.

## 파일 구성

- `my_agent.py`: 외부 패키지 없이 실행되는 규칙 기반 에이전트 v0
- `context.md`: 에이전트가 읽는 프로젝트 맥락
- `todo.md`: Week 11 체크리스트와 Week 12 개선 계획
- `AGENTS.md`: 여러 코딩 에이전트가 지켜야 할 공통 규칙
- `GEMINI.md`: 보조 검토 에이전트용 규칙
- `vibe_prompt.md`: `my_agent.py` 첫 버전을 만들기 위한 바이브코딩 프롬프트
- `agent_output.md`: `my_agent.py` 실행 후 생성되는 결과 보고서

## 실행 방법

```powershell
python .\my_agent.py
```

이 폴더를 다른 에이전트 폴더로 옮긴 뒤에도 같은 명령으로 실행할 수 있습니다. 단, 원래 수박게임 프로젝트 루트 안에 있을 때는 `src/main.js`, `public/faces`, `public/media`, `package.json`을 추가로 감지해서 더 자세한 중간 결과를 출력합니다.

`멀티에이전트 프로젝트/week11-suika-agent`처럼 문서 프로젝트 안에 독립 모듈로 들어간 경우에는 게임 루트를 찾지 못할 수 있습니다. 이때도 오류는 아니며, `context.md`와 `todo.md`를 기준으로 실행 보고서를 생성합니다.

## Week 11 체크

- 준비 파일 4개 확인: `AGENTS.md`, `GEMINI.md`, `context.md`, `todo.md`
- 일정공지 예시를 수박게임 작업공지 에이전트로 변환
- `my_agent.py` 작성
- 외부 패키지 없이 실행
- 함수 역할 3개 이상 분리
- 중간 결과 출력
- 12주차 확장 방향 결정: Groq API 먼저 연결, 외부 도구는 그 다음 단계
- 12주차 개선 항목을 `todo.md`에 기록
