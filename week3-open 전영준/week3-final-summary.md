# Week 3 최종 요약

## 완료한 실습

- 실습 1: 기존 MCP 서버를 stdio로 연결하고 호출 기록과 오류 사례를 남겼다.
- 실습 2: 규칙 파일 적용 전후 요약 결과를 비교하고 비교 문서를 남겼다.
- 실습 3: 읽기 전용 최소 MCP 서버 `list_markdown_files`를 직접 만들고 정상/실패 호출을 검증했다.
- 실습 4: plugin 묶음 구조 예시를 만들었다.
- 실습 5: hooks와 memory를 붙여 문서 규칙을 자동 검증과 지속 문맥으로 확장했다.
