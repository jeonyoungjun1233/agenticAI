# 문서 요약 skill

이 skill은 `week3-minimal-server`와 함께 사용할 수 있는 예시 skill이다.

## 목적

- 문서 요약 작업을 할 때 출력 형식과 검증 항목을 일정하게 유지한다.

## 작업 규칙

- 출력은 항상 `output/` 아래에 저장한다.
- 핵심 요약 전에 검증 항목 3개를 먼저 쓴다.
- 불확실한 내용은 추측하지 말고 `확인 필요`로 표시한다.
- 실행 후 어떤 파일을 읽고 어떤 파일을 만들었는지 남긴다.

## 권장 흐름

1. 문서 파일을 읽는다.
2. 핵심 bullet을 3~5개로 정리한다.
3. 검증 항목 3개를 먼저 적는다.
4. 결과 파일 경로와 확인 필요 항목을 남긴다.
